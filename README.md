# Shaolin Slurp Ramen - Bayou Dojo WebForge Redesign

Static GitHub Pages demo for a **Cajun-ramen fusion food truck**. The redesign keeps the existing no-framework HTML/CSS/JS architecture and changes the customer journey to **route -> menu -> catering**.

## Files
- `index.html` public demo
- `css/styles.css` design system + responsive styling
- `js/site-data.js` editable route/menu/token/SEO data
- `js/main.js` navigation, route/menu rendering, catering mailto flow
- `.webforge/design-os.html` development-only design controls
- `DESIGN.md` selected WebForge direction
- `docs/webforge/WEBFORGE_QA.md` design-loop score and launch blockers

## Run
Open `index.html` or serve the repo with any static web server. No build step is required.

## Important
Schedule, locations and menu prices in this branch are **demo concept content** until verified for a real launch.
