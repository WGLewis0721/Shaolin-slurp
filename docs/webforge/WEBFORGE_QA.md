# WebForge QA - Cajun Ramen Redesign v2

## Why v2 exists
The first Bayou Dojo pass was functional and distinctive but still read like a flat design-system exercise. User review: **5/10**. The corrective direction is food-first, photography-led, and closer to a premium restaurant/food-truck brand experience.

## V2 design-loop changes
- Replaced abstract hero bowl illustration with truck + real food photography.
- Added stronger appetite appeal and a next-stop strip in the hero.
- Added a signature-bowl spotlight before the longer brand story.
- Reworked the fusion explanation into Louisiana pantry x ramen technique.
- Increased editorial contrast with condensed display type + serif accents.
- Reduced generic grid/demo feel while preserving route/menu/catering clarity.
- Kept the static GitHub Pages architecture and editable `site-data.js` model.
- Updated the development-only Design OS to match the new hero and asset system.

## Quality gate review
- Distinctiveness/art direction: strong
- Visual hierarchy/composition: strong
- Client/brand fit: strong
- Usability/navigation: strong
- Responsive/mobile: designed for route/menu/catering priority
- Conversion clarity: strong
- Copy quality: specific and non-generic
- Accessibility: reduced-motion support, semantic structure, keyboard focus path retained
- Technical feasibility/performance: static HTML/CSS/JS, no added framework or backend

## Remaining launch blockers
- Replace demo route with verified serving locations/times.
- Confirm menu, prices, social profiles, and final photography.
- Connect a real ordering platform only if the business needs online ordering.
